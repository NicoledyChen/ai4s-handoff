# AI4S × MaSIF：基础设施架构

版本：概念设计 v0.1 · 2026-09-10

配图：[基础设施架构 PNG](diagrams/01-infra-architecture.png) · [可编辑 SVG](diagrams/01-infra-architecture.svg)。配图描述目标逻辑关系，不是当前部署状态。

## 1. 这次展示什么

把团队已用 AI 跑出的 MaSIF binder 探索成果产品化：以 Skill 固化输入、参数、决策和产物，让框架稳定复现接近的工作轨迹，并让科学家在关键节点理解、决定与接管。沿用原始 Lumen 的“同一对象、多级投影”，由分析、可视化、证据整理、流程执行等任务类型承载工作，角色和群聊提供可寻址的协作入口。

团队探索层与产品界面层要分开：Word 中记录的研究结果是已有成果；此前 Lumen 是静态 UI 原型，现在把这些成果、交互和工作合同接起来。当前展示先演绎已有轨迹，产品化继续打通 Harness 与科学工具的接入。本轮没有重新执行科研计算，不影响既有研究成果的真实性。

## Skill 如何把已有探索变成稳定流程

四个关键节点分别对应 SiteSelection、RosettaDesign、GraftSelection、AF3Review 工作 Skill。每个 Skill 固定输入契约、参数和工具版本、必须由人决定的边界、产物格式、验证规则、失败与恢复路径。模型可以灵活解释和编排，但不能擅自跳过检查或改写科研目标。

稳定不要求随机输出或自然语言逐字一致，而要求同类输入进入可比较的执行路径，关键决定和产物可追踪，异常后能接续。先用团队已有轨迹作为回归样例，再用真实接入验证同一合同。

## 2. 最小结构：复用底座，只增加工作语义

```text
科学家 ⇄ 角色／群聊／结果工作面
                   ⇅
       Grok 式 HCI 与 Harness 适配边界［待核验］
                   ⇅
         Work IR：任务合同、依赖与决定
                   ↓
    分析／可视化／证据整理／流程执行任务
         ↙                         ↘
回放适配器［demo 待实现］    原生执行适配器［未来］
         ↘                         ↙
 Notebook／Git／数据目录／结构文件／计算平台
                   ↓ 引用、版本与验证
  角色的 PresentationPlan → Lumen Projector
                   ↓
 Signal → Summary → Workbench → Analysis → Source
```

图是产品化的目标连接关系，不是对团队科研能力的否定。展示中的角色对话用于呈现已有轨迹；具体来源和当前执行方式在详情中可查，主画面不反复张贴提示。继续优先复用宿主调度、工具和权限，不再建设并行的通用 Agent 平台。

Git 管代码与配置版本，数据目录管数据快照，原生计算平台管实际作业状态。Work IR 只保存合同、引用、索引与可重建投影；开放记录可随项目带走。人在 Notebook 或原生工具里的修改需回流，不能被聊天缓存覆盖。

## 3. 四节点：类型合同 → 产物 → 基础设施

所有节点共用合同：`taskId / revision / taskType / inputRefs / exactVersions / constraints / expectedOutputs / verificationPlan / decisionRef / executorRef / presentationContract`。输入、验收条件和批准范围绑定版本；显示角色、实际 actor、模型/session、权限引用分别记录。以下均为拟建合同。

### N1｜阶段 4：位点确认

以可视化和证据整理任务为主。输入结构、链与残基编号，以及已有 mesh、位点评分和描述符；合同检查对应关系与缺失项。用户确认 site、可选 target residue 和允许的位点偏移，不能把“查看该位点”当作“批准搜索”。

产物是版本化位点选择、结构视图规格和决策卡；落在原始结构、表面文件、选择配置及领域 viewer。角色解释覆盖关系与未决生物学信息。没有真实 mesh 时只能显示明确标注的示意，不能由文档文字伪造分子表面。

### N2｜阶段 8：设计边界

以流程执行任务承载配置，以可视化任务解释可设计范围。输入选定复合物与 motif；合同明确 target/binder 链角色、固定与可设计残基、骨架柔性、氨基酸集合及采样预算。改变研究对象或预算须重新批准。

产物是设计配置、运行清单、输出结构、指标和前后叠合；回落到 Rosetta 原生配置、作业日志、结果目录和分析 Notebook。执行验收检查完成与输出可读，科学复核检查漂移和可比较性，两者分开。回放不能生成新的能量结果或声称配置已被 Rosetta 执行。

### N3｜阶段 11：母体选择

以数据分析和可视化任务承载。输入逐候选指标、seed/scaffold/结构模式映射及已有筛选依据；合同区分硬约束、批内排序与来源配额。用户确认母体数量、来源配额与优先保留模式。

产物是母体清单、淘汰原因、Pareto/来源视图与决策差异；落在候选数据、筛选脚本或 Notebook、版本化选择文件。手册文档实例为“1864 个可解析结果 → 633 个保留结果，但只来自 3 个 seed ID”，用于说明数量不等于多样性，不是本次运行成果。当前未提供完整逐候选表，动态重算完整筛选分布属于待接入；只有拿到逐行真实离线数据，才可声称完成该批次本地分析，不能从汇总数反造分布。

### N4｜阶段 12：AF3 复核

流程执行、分析与证据整理任务共同承载。输入母体序列/结构、target、设计位点和批准的 model seeds；合同保留预测文件与候选的准确映射。用户决定深筛对象和重复范围，指标冲突或结合位点不一致时暂停。

产物是结构叠合、完整界面 PAE、相关置信度记录、异常清单及复核决定；回落到 AF3 输入/输出、指标文件和 Notebook。手册实例每个输入仅用一个 model seed，不能据此展示多 seed 一致性结论。缺少某项原始结果时标为缺失；预测复核不等于实验有效性。

## 4. 事件、决定、版本和谱系如何贯通

**事件来自实际发生的动作。** 演示记录用户选择、视图修改、回放跳转和本地导出；回放包中的历史事件保留原时间与来源，本次播放时间另记。原始时间或日志未提供时记为未知，合成对话不可伪装成曾经发生的审批。`submitted / running / succeeded / failed / unknown / canceled` 描述执行，`unreviewed / reviewed / needs-review` 描述复核，不能把播放结束写成计算成功。

**决定是一等产物。** 每张卡绑定阶段、输入版本、当前方案、建议与备选、依据、风险、用户选择和理由。预计候选量或计算量若没有观测或测算依据，写“待测”，不伪造精确估计。批准引用明确动作、输入版本、范围和失效条件；PULL、群聊共识与角色身份均不扩权。

**谱系保留分支，不只保留胜者。** 记录 target/chain/site → MaSIF seed → 簇代表 → Rosetta 设计 → graft/scaffold → 母体 → AF3 输入及 model seed → 复核结果。每条边引用产物版本、变换和决定，并保存失败与淘汰理由。参数变化产生新修订，旧结果可读，下游依赖标为需复核；没有原始映射的边标 `traceability gap`，不由模型补全。

**多级信息共用同一事实。** 角色提出 PresentationPlan，Projector 检查对象版本、受众、证据引用与必要限制。Signal 起就保留来源类别、运行/复核状态、关键不确定性及下钻入口；到 Source 可打开原生产物。保存外显依据，不要求披露模型私有推理。展示过滤只改变 view；分析排除改变方法与版本。

## 5. 真交互、回放与未来能力的边界

- **demo 中拟实现的真交互：** 层级展开、对象联动、位点/候选选择、决策留档、视图过滤、版本比较、导出与恢复。只有落盘并重新读回验证后，才称“已保存”。
- **回放：** 科学阶段推进、既有结构和指标呈现、脚本化角色响应。每步显式显示“回放”，提供来源入口；缺少对应参数的回放分支时停在提案，不伪装重算。
- **未来接入：** 真实模型路由、Grok/Harness 生命周期、科学作业提交/取消/查询、身份与权限。接口能力、许可、环境和可观察性验证完成前，不承诺已具备。

记录分开保存 `sourceKind: document-example / offline-result / synthetic` 与 `executionMode: replay / local-interaction / live`。真实离线结果仍可能处于 replay；真实点击不会把 synthetic 变成科学证据。合成小样本使用 `DEMO-*` 独立命名空间和醒目标识，不能与来源实例混成同一候选漏斗。

## 6. 最低接入与恢复边界

首个可交互闭环需要：可复用 Lumen 工作面；含来源、校验值和文件映射的回放 manifest；上述任务/决定/版本合同；确定性回放适配器；可落盘的事件记录；角色展示计划与保真校验；来源打开和导出入口。至少验收一条正常分支、一条缺失证据分支、一次撤销和一次恢复。此清单是待实施范围，不是已完成能力。

未来执行适配器另需验证提交/查询/取消、幂等键、作业 ID、输出读取、环境版本和现行权限。查询不到状态时记录 unknown，先核对再重试，避免重复计算；取消请求不等于作业已停。撤销阻断尚未提交的动作；已发生的外部效果不能靠倒退界面消除，需确认平台状态并记录残余效果。

恢复从 checkpoint 读取目标、版本、决定、待交付与未决效果，再对照原生状态；过期批准不得复活。回放可回到上一检查点，但已保存决定以撤销记录保留。若宿主无法观察或约束某条执行路径，明确追溯缺口并收缩自动执行范围。
