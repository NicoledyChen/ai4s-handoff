MaSIF binder 设计流程 参数选择与 Agent 交互指南
基于 canine trka af3 A 实例的参数决策手册
本手册聚焦 MaSIF binder 设计中真正需要判断的内容，包括每个阶段的目标、参数含义、收紧或放宽参数的后果、判断参数是否合适的证据，以及把整条流程交给 Agent 后应如何与用户交互。
这条流程的核心是逐级压缩候选空间，同时保护结构多样性。任何阈值都不应脱离候选数量、分数分布、结构质量和计算预算单独决定。Agent 的任务也不应只是自动运行计算，而应在每个关键节点把证据、默认建议、替代选项和后果一并呈现给用户。

一 参数选择的总体原则
先确定本轮任务类型
同一参数在探索轮和收敛轮中应有不同取值。探索轮的目标是发现可行结构模式，应适当扩大召回并保留多样性；收敛轮的目标是形成实验候选，应提高几何、能量、置信度和可开发性的最低要求。若没有先说明任务类型，Agent 很容易给出看似精确但不适合当前阶段的阈值。

区分硬约束和排序指标
硬约束用于排除原则上不可接受的结构，例如主链严重碰撞、目标链错误、明显缺失界面或设计位点偏离。硬约束应在排序前执行。
排序指标用于比较已经合格的候选，例如 nn score、界面能、形状互补性、ipTM 和 ipSAE。排序指标不适合单独充当淘汰线。
相对阈值按照当前批次的分位数保留候选，适合控制数量；固定阈值保证最低质量。两者应同时存在。
当多个指标互相冲突时，应保留 Pareto 前沿或分层代表，而不是先把所有指标压成一个未经校准的总分。
用候选数量反向校准阈值
每一步都应先估计下游能够处理的候选量，再选择阈值。若下游只能处理约 60 个复合物，搜索阶段得到数千个候选时就需要先聚类；若搜索只得到十几个候选，则继续收紧评分通常没有意义，应先检查位点、seed 库覆盖和碰撞条件。当前实例从 208 个 MaSIF 匹配压缩到 60 个 Rosetta 输入，属于先保护结构模式再控制算力的典型情况。
保留多样性
每次筛选后都同时报告候选总数、独立 seed 数、结构簇数和 scaffold 数。总数很大不代表来源丰富。
对单一母体或单一 seed 设置配额，避免一个高分家族占满后续算力。
为稀有但几何合理的构象保留少量名额。它们可能在 Rosetta 或 AF3 阶段超过早期高分候选。
Agent 的通用回答格式
1.  显示当前输入是否完整以及不能自动判断的生物学信息。
2.  显示关键指标分布、候选数量、结构代表和异常项，而不是只给出成功或失败。
3.  给出一个推荐参数组，并同时给出宽松和严格两个备选组。
4.  解释每个备选组预计改变的候选数量、结构多样性和计算量。
5.  要求用户只确认会改变科学问题或计算预算的选择，其余采用可追溯的默认值。
二 流程总览与候选漏斗
MaSIF 首先寻找与目标表面在几何和化学特征上互补的结构片段。RMSD 聚类把相似 seed 合并为结构模式。Rosetta 优化局部构象和界面序列，MotifGraft 把关键接触 motif 转移到可折叠 scaffold。AlphaFold 3 和后续界面分析作为验证步骤，检查候选是否仍保持目标位点与合理界面。

三 Target 输入
当前项目从用户指定的蛋白结构开始。输入可以是本地 PDB 文件，也可以是已有的 PDB 条目；两种方式都需要明确 target 名称和链 ID。项目随后以所选结构和链生成表面、位点预测和描述符。
当前代码支持的输入选择
结构来源  用户可以提供本地 PDB 文件，或提供已有 PDB 条目作为输入。
Target 链  输入名称需要包含链 ID，后续表面计算和 seed 搜索以该链作为 target。
残基编号  若下一阶段启用 target residue，残基号和链必须与输入 PDB 保持一致。

输入结构名称、来源方式和选定的 target 链。
Target 链的残基编号范围，以及拟用于 target residue 的残基是否存在。

Agent 应给出的参数建议
若提供本地 PDB，建议先确认文件中的链 ID 与用户选择一致；若使用 PDB 条目，建议确认条目和链 ID 能够正确获取。
若指定残基不存在于所选链，建议先核对 PDB 残基编号，再进入位点限制设置。
需要用户确认  确认输入结构、target 名称、链 ID，以及是否计划在下一阶段指定 target residue。
进入下一步的条件  输入结构和 target 链能够唯一识别，表面与描述符计算成功完成。
四 Target 表面与设计位点
表面计算把原子结构转换为 mesh、局部几何化学描述符和潜在结合位点分数。num sites 决定保留多少个候选表面区域；target residue 可进一步把搜索限制在特定残基附近。两者解决不同问题：前者控制位点数量，后者表达生物学先验。

表位明确时推荐单一主 site 加一个备选 site；表位未知时推荐保留 2 到 3 个几何差异明显的位点。

进入下一步的条件  每个入选 site 都具有可解释的生物学目的和足够的可接近表面。

阈值联动策略
候选过少  先确认 site 和 seed 库覆盖，再小幅放宽 desc dist 或 iface；nn score 已较严格时，可做有限幅度的分层试验。不要同时放宽碰撞和所有评分阈值。
候选过多  先收紧 desc dist 或 nn score，并观察被删除候选是否集中在同一结构家族。若多样性下降明显，应保留原阈值并把压力转移到聚类阶段。
碰撞多  主链碰撞保持零容忍；若只是少量侧链重叠，可保留到 Rosetta 松弛，但应比较松弛前后接触恢复情况。
跨物种 seed 库  优先把物种或结构库作为分层来源报告。若某一来源独占候选，不应直接认为它更优，需要排除库规模差异。
Agent 应展示的结果
三个评分的一维分布和两两散点图，标出当前阈值及其附近候选。
每个 site 和每个 seed 来源的命中数、独立结构数、碰撞类型及代表性复合物。
阈值敏感性预览，例如每个阈值上下调整一个小步后候选数量与多样性的变化。
Agent 应给出的参数建议
以当前参数为平衡方案，同时给出高召回和高精度两套建议，并估计进入聚类或 Rosetta 的数量。
候选来源单一时建议增加 seed 来源；候选几何普遍冲突时建议回到 site 选择，而不是继续放宽评分。
需要用户确认  确认搜索模式、site、seed 来源、目标候选规模和可接受的重计算成本。
进入下一步的条件  每个目标 site 都得到足以评估的候选，且代表结构不存在不可恢复的主链碰撞。
六 搜索结果诊断
搜索完成后不能直接按单一分数取前若干名。应先判断候选是否足够、是否集中于少数来源、三个评分是否一致，以及几何失败主要来自何处。当前实例的 208 个匹配中，site 0 有 194 个，site 1 只有 14 个，因此两个 site 应分别诊断。
决定重搜还是进入聚类
候选很少且评分也接近阈值  优先重查 site、target residue 和 seed 覆盖，再考虑放宽搜索。
候选很多但结构高度相似  直接进入聚类比继续收紧评分更能保留可解释性。
评分很好但碰撞集中  先区分主链碰撞和侧链碰撞。主链冲突通常需要回退，侧链冲突可让 Rosetta 评估是否可恢复。
不同评分给出相反排序  保留冲突候选作为单独层级，检查它们是否代表不同表面化学或不同几何模式。
Agent 应展示的结果
按 site 划分的候选漏斗、评分分布、来源构成和结构缩略图。
高分候选的接触图和碰撞标记，以及接近阈值候选的敏感性列表。
重搜、直接聚类和直接 Rosetta 三条路线的预计任务量。
Agent 应给出的参数建议
候选量超过下游预算时建议聚类；候选量少且多样性不足时建议重搜；数量适中且结构差异明显时可直接进入 Rosetta。
当前实例建议对 site 0 聚类，对 site 1 作为独立小集合审查，避免被大 site 的统计分布淹没。
需要用户确认  确认每个 site 采用重搜、聚类或直接优化中的哪条路线。
进入下一步的条件  用户能看到数量、质量和多样性三方面证据，并确认下游计算预算。
七 片段提取与结构聚类
聚类前先从接触最密集的连续残基中提取固定长度片段，再计算候选之间的 C alpha RMSD。当前 alpha helix 流程使用 12 个残基、3 Å 接触距离、6 个聚类和每类前 10 个候选。MDS 只用于展示，最终聚类判断应回到原始 RMSD 和结构叠合。

聚类参数的详细选择
先比较 4 到 10 个聚类的稳定性。若小幅改变随机初始化就导致成员大规模交换，说明当前聚类数缺乏稳定结构含义。
查看每簇内原始 RMSD 的中位数和上界。二维 MDS 图的视觉分离不能替代这些数值。
每类保留数量不必完全相同。大簇可按质量和子多样性多留，稀有小簇至少保留一到两个结构代表。
alpha helix 适合连续固定长度片段；beta hairpin 或不连续 motif 应使用能够表示两段接触的定义，不能照搬单螺旋的 12 残基窗口。
Agent 应展示的结果
RMSD 分布、聚类稳定性曲线、每簇大小、簇内 RMSD 和簇间最小 RMSD。
每个簇的中心结构、前若干候选叠合图和接触残基序列 logo。
不同聚类数下的代表覆盖率和预计 Rosetta 任务量。
Agent 应给出的参数建议
推荐使结构模式稳定且下游规模可接受的最小聚类数；若 6 类已稳定，可保持当前值。
建议按簇大小和稀有性分配保留数，而不是机械地每类相同；若需要保持当前可复现口径，可继续每类 10 个。
需要用户确认  确认片段定义、聚类数、每簇配额和是否保留稀有构象。
进入下一步的条件  代表集合覆盖主要结构模式，且每个代表都能映射回原始候选和接触位点。
八 Rosetta 松弛与界面设计
Rosetta 先松弛 target seed 复合物，再在界面邻域内进行侧链重排和 binder 序列设计。这里最重要的人工判断是链角色、可设计残基、骨架柔性和界面范围。当前设置保持 target 序列不变，允许 binder 设计，排除 Cys，并使用 10 Å 邻域、8 Å 界面定义、界面权重 3、FastRelax 10 次和 FastDesign 1 次。

选择细则
骨架置信度高且 motif 几何必须保持时，应限制 binder 主链变化；若 target 局部来自预测且不确定，可允许小幅 target 松弛，但要监测表位漂移。
可设计氨基酸集合应结合表达体系和实验目的。排除 Cys 可降低非预期二硫键风险，但若 scaffold 依赖天然二硫键则不能统一排除。
界面权重提高后必须同步检查 binder 单体稳定性、埋藏极性原子和疏水表面，避免只追求界面能。
采样是否充分应由重复运行的能量分布和结构 RMSD 决定。若独立重复给出相似解，增加 repeats 的收益有限。

可设计残基、固定 motif 残基和 target 侧链重排区域的三维着色图。
多次独立运行的收敛图，以及每个结构簇成功完成的比例。
Agent 应给出的参数建议
默认固定 target 序列并保护 seed motif；根据局部结构置信度建议骨架柔性。

需要用户确认  确认 target 与 binder 的链角色、可设计残基、骨架柔性、允许氨基酸集合和采样预算。
进入下一步的条件  任务完整，结构没有明显漂移，并且每个聚类都有可比较的能量与几何结果。
九 Rosetta 结果筛选与二级结构判断
筛选同时使用绝对界面能、按面积归一的界面能、埋藏未满足氢键、形状互补性和氢键数量。当前实例对 nddg post 与 ddg post 使用第 70 百分位，对 buried unsatisfied hydrogen bonds 使用不高于 1，对 shape complementarity 使用高于 0.65，并要求 alpha 接触比例不低于 0.5。

如何避免分位数误导
分位数只能保证保留一定比例，不能保证结构达到实验所需质量。若整批结果差，第 70 百分位仍会放入差结构。
应先应用固定底线，再在合格集合中使用分位数控制数量。固定底线应根据同类项目的阳性和阴性参照校准。
若不同结构簇的分布差异很大，应在簇内保留代表，再进行跨簇比较，避免大簇决定全局分位数。
二级结构接触比例必须与 seed 类型对应。alpha 与 beta 候选应分支处理，并使用各自的接触定义。

进入下一步的条件  入选 seed 同时满足能量、几何和 motif 接触要求，并保持多个结构来源。

十二 AlphaFold 3 复合物验证
AF3 用重新预测检验候选是否仍能形成目标界面。当前实例的输入均使用一个 model seed。单 seed 适合快速初筛，但不足以衡量随机性。临界候选和最终实验候选应增加 model seeds，并比较结合位点、binder 构象和界面置信度是否一致。
需要同时检查的证据
结合位点一致性  AF3 预测界面必须覆盖原始 MaSIF 设计位点，binder 不能翻转到另一个高置信表面。
界面置信度  pair ipTM 应与完整界面 PAE 和 ipSAE 一致。单个最小 PAE 不能代表整个界面。
binder 自身折叠  检查 binder 的局部置信度、整体折叠和不同 model seeds 的构象一致性。

十三 界面分析与实验候选排序
AF3 通过后，再用松弛后的界面能、界面面积、packstat、shape complementarity、ipSAE 和碰撞检查交叉排序。当前 150 个结果没有报告碰撞，pair ipTM 为 0.08 到 0.85，平均 0.269；pair PAE 最小值为 1.14 到 27.01，平均 15.011；interface dG 为 -94.851 到 -24.101；dSASA 为 983.528 到 2997.622；packstat 为 0.477 到 0.749；shape complementarity 为 0.433 到 0.814。范围较宽，说明最终选择不能依赖单一指标。
最终排序顺序
1.  先执行结构硬约束，排除结合位点错误、binder 翻转、明显碰撞和低置信折叠。
2.  在合格结构中检查不同 model seeds 的界面一致性，并按结构母体和来源分组。
3.  使用 pair ipTM、完整界面 PAE 和 ipSAE 判断预测置信度。
4.  使用 interface dG、dSASA、packstat、shape complementarity、BUNS 和氢键判断界面物理合理性。
5.  按母体、seed、scaffold 和界面模式去冗余，形成覆盖不同结构假设的实验组合。
指标冲突的处理
pair ipTM 高但界面能差  说明模型相信该相对构象，但界面物理质量仍可能不足，应检查埋藏极性和堆积。
界面能很好但 PAE 高  可能是松弛后能量优化了一个 AF3 不稳定的姿态，不能仅凭能量入选。
dSASA 很大但归一能量一般  可能靠大界面获得绝对 ddG，需要警惕非特异性和过度疏水。
同一母体的多个预测重复均保持相同界面，可提升该母体的可信度，但最终实验组合仍应给其他结构模式留出名额。
Agent 应展示的结果
硬约束通过率、各指标分布、指标相关图和 Pareto 前沿。
每个候选的设计结构与 AF3 结构叠合、界面接触图和多 seed 一致性。
去冗余前后的母体、seed、scaffold 和界面模式数量。
Agent 应给出的参数建议
给出高置信、高物理质量和高多样性三类候选，并解释每类的取舍。
建议实验组合包含主力候选、结构多样性候选和一到两个边界候选，而不是只按总分截断。
需要用户确认  确认实验候选数量、每个家族配额、是否纳入边界候选以及实验端的表达和功能限制。
进入下一步的条件  每个最终候选都有完整证据链、明确入选理由和至少一个结构层面的非冗余价值。

Agent 何时应自动继续
输入格式检查、评分汇总、分布计算、聚类稳定性评估和报告生成可以自动执行。
用户已经确认的目标、链角色、表位和预算没有变化，且结果落在预先批准的质量和数量范围内时，可以自动进入下一步。
重复运行只改变随机 seed 而不改变科学假设时，Agent 可以按已批准的重复次数自动完成并汇总。
Agent 何时必须暂停
Target 输入、链 ID 或设计位点存在歧义。
放宽阈值会改变 binder 所针对的表位，或会允许主链碰撞。
候选数量明显超出预算，必须在多样性和质量之间重新分配。
alpha 与 beta motif 需要采用不同处理分支。
AF3 多 model seeds 给出不同结合位点，或最终候选的关键指标相互冲突。
推荐的决策卡片
每个决策点应形成一张可保存的决策卡片，包含阶段名称、当前参数、结果摘要、推荐参数、两个备选参数、预计候选数、预计计算量、主要风险、用户选择和选择理由。参数推荐必须附带观测依据，例如分布拐点、结构叠合、来源多样性或多 seed 一致性，不能只写经验值。
建议的默认交互节奏
1.  开始时确认 Target 输入、链 ID、是否指定 target residue 和总计算预算。
2.  完成表面计算后确认 site 与 target residue，这是第一个必须人工确认的结构节点。
3.  完成 MaSIF 搜索后展示阈值敏感性和候选多样性，由用户选择重搜、聚类或直接优化。
4.  完成聚类后确认聚类数和每类配额，这是计算预算的主要分配节点。
5.  Rosetta 筛选后确认能量、几何和二级结构联合门槛。
6.  MotifGraft 后确认母体配额和结构去冗余方式。
7.  AF3 初筛后确认哪些候选需要增加 model seeds。
8.  最终界面分析后确认实验组合和每个候选的入选理由。
Agent 状态中必须长期保存的内容
Target 输入、链 ID、site 和可选的 target residue 设置。
每一步的参数、候选 ID、父子关系、结构簇和淘汰原因。
每个参数选择的推荐理由、用户决定和预算变化。
随机 seed、重复次数以及同一候选在不同模型或不同重复中的一致性。
最终候选从 MaSIF seed 到 scaffold 和 AF3 结果的完整谱系。
结语
MaSIF binder 设计的自动化重点不是把所有步骤连成一个按钮，而是把每次参数变化与候选数量、质量、多样性和计算成本联系起来。一个可靠的 Agent 应在关键输入或科学假设发生变化时暂停，在证据充分且选择已被授权时自动继续，并为每个最终候选保留从 target 位点、seed、结构母体到 AF3 验证的完整决策记录。
