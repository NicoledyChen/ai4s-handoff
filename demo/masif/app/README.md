# Lumen AI4S MaSIF 产品化演示

打开 index.html 即可使用；assets 文件夹需与它一起保留。所有核心界面交互在本地完成，不需要配置模型密钥。

建议从位点开始，点击右上角“演示下一幕”走过四个节点。可以点名角色、展开五级信息、修改设计规则、选择或撤销候选、记录复核处置，并导出本地决定。

通过 ?session=investor 可以使用独立的展示记录，不会删除其他演示的状态。需要完全从头演示时，在说明面板选择重置；只影响该session。

这是团队已有AI科研探索的产品化界面。报告数字来自团队记录；个体候选和对话用于交互编排。当前页面不提交真实科研作业，来源与范围在说明/证据面板中可查。
